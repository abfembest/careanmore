    Using this website

    We want as many people as possible to be able to use this website. For example, you should be able to:

    • zoom in up to 400% without the text spilling off the screen
    • navigate the whole website using just a keyboard
    • pause the moving slideshow on the home page
    • use the website with a screen reader
    • use the website on a phone, tablet or computer

    The website respects your device’s “reduce motion” setting and uses high-visibility focus styles.

    Compliance status

    This website has been designed to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA. It has not yet been independently audited. Any known issues will be listed here.

    Feedback and contact information

    If you find a problem with this website or need information in a different format, such as large print or easy read, please contact us.
